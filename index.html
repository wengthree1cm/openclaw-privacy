Privacy Policy

OpenClaw Gmail Integration

This application accesses Gmail API to read emails on behalf of the user for personal email management purposes.

Data Usage

  • We only read email metadata and content
  • No email data is stored on external servers
  • All processing happens locally on user's device
  • Data is not shared with third parties
  • User can revoke access anytime through Google Account settings

Data Security

  • OAuth 2.0 authentication for secure access
  • Tokens stored locally and encrypted
  • No persistent storage of email content
