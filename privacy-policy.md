# Privacy Policy

## OpenClaw Gmail Integration

This application accesses Gmail API to read emails on behalf of the user.

### Data Usage
- We only read email metadata and content
- No data is stored on external servers
- All processing happens locally on user's device

### Data Security
- OAuth 2.0 authentication
- Tokens stored locally and encrypted
- User can revoke access anytime
